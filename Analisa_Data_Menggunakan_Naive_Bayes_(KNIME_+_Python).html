Analisa Data Menggunakan Naive Bayes (KNIME + Python)#

1. Pendahuluan#

Pada tugas ini dilakukan analisis data penumpang kapal RMS Titanic dengan tujuan untuk memprediksi apakah seorang penumpang akan selamat atau tidak dari tragedi tersebut. Kondisi penumpang selamat atau tidak selamat termasuk ke dalam kategori klasifikasi biner, karena hanya memiliki dua kemungkinan hasil, yaitu selamat (1) dan tidak selamat (0).

Data yang digunakan berisi beberapa informasi penting terkait profil penumpang, seperti:

  • Pclass: Kelas kabin penumpang (Kelas 1, 2, atau 3).

  • Age: Usia penumpang.

  • SibSp & Parch: Jumlah anggota keluarga yang ikut dalam perjalanan.

  • Fare: Harga tiket yang dibayarkan.

2. Konsep Naive Bayes#

Metode yang digunakan pada analisis ini adalah Gaussian Naive Bayes. Secara sederhana, metode ini bekerja dengan menghitung peluang suatu data masuk ke dalam kelas tertentu (misalnya kelas “Selamat” atau “Tidak Selamat”) berdasarkan fitur yang dimilikinya, seperti usia, tarif tiket, dan kelas kabin. Algoritma ini disebut “Naive” karena mengasumsikan bahwa setiap fitur berdiri sendiri dan tidak saling memengaruhi satu sama lain dalam menentukan hasil akhir.

Karena dataset Titanic memiliki fitur berupa angka kontinu (seperti Age dan Fare), model menggunakan pendekatan Gaussian yang mengasumsikan bahwa data tersebut mengikuti distribusi normal atau kurva lonceng. Setelah semua peluang dari masing-masing fitur dihitung dan dikalikan, model akan memilih kelas dengan nilai probabilitas terbesar sebagai hasil prediksi akhir.

Dasar dari metode ini adalah Teorema Bayes, yang dirumuskan sebagai berikut:

\[P(C|x) = \frac{P(x|C) \cdot P(C)}{P(x)}\]

Rumus Distribusi Gaussian (Normal):

\[P(x_i | y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} e^{-\frac{(x_i - \mu_y)^2}{2\sigma_y^2}}\]

3. Asumsi Naive Bayes#

Metode ini bekerja dengan asumsi bahwa setiap fitur (seperti usia, kelas kabin, dan harga tiket) bersifat independen, artinya informasi tersebut dianggap tidak saling berhubungan dalam menentukan hasil akhir. Meskipun di dunia nyata faktor-faktor ini mungkin berkaitan, asumsi ini digunakan agar komputer bisa menghitung peluang dengan sangat cepat dan efisien. Selain itu, karena menggunakan jenis Gaussian, model mengasumsikan data angka (seperti usia) tersebar secara normal atau mengikuti pola kurva lonceng. Oleh karena itu, penghapusan data kosong melalui perintah dropna() sangat penting agar perhitungan rata-rata dan penyebaran data tetap akurat.

4. Preprocessing Data#

Sebelum data digunakan dalam model, dilakukan beberapa tahap preprocessing.

4.1 Missing Value#

Data yang kosong perlu ditangani karena tidak bisa langsung diproses oleh model. Pada tahap ini:

  • Data numerik diisi menggunakan nilai tengah (median)

  • Data kategori diisi dengan nilai yang paling sering muncul (modus)

  • Kolom target tidak diubah sembarangan agar hasil prediksi tetap akurat

Rumus median: $\(Median = \begin{cases} x_{(n+1)/2} & \text{jika } n \text{ ganjil} \\ \frac{x_{n/2} + x_{(n/2)+1}}{2} & \text{jika } n \text{ genap} \end{cases}\)$

4.2 Number to String#

Tahap ini bertujuan untuk mengubah tipe data dari angka (numeric) menjadi teks (string). Pada dataset Titanic, langkah ini dilakukan karena:

  • Kolom Survived: Meskipun berisi angka 0 dan 1, kolom ini sebenarnya adalah label kategori (0 = Tidak Selamat, 1 = Selamat). Mengubahnya menjadi string membantu model memperlakukan kolom ini sebagai target klasifikasi, bukan angka matematika.

  • Kolom PassengerId: Angka ini hanyalah nomor urut atau identitas unik penumpang yang tidak memiliki nilai matematis (tidak bisa dijumlahkan atau dirata-rata), sehingga lebih tepat disimpan sebagai teks.

Logika Perubahan Tipe Data: $\( \text{Data Angka (1, 0)} \xrightarrow{\text{Konversi}} \text{Data Teks ("1", "0")} \)$

Dengan mengubah kolom target menjadi string, proses evaluasi pada node Scorer nantinya dapat membaca hasil prediksi dengan benar sebagai sebuah kategori kelas.

5. Workflow KNIME#

Alur proses yang digunakan adalah:

CSV Reader —> Missing Value —> Number to String —> Python Script —> Scorer —> Table View

6. Penjelasan Node#

6.1 CSV Reader#

Digunakan untuk membaca dataset dari file CSV. Pada tahap ini data dimasukkan ke dalam KNIME.

6.2 Missing Value#

Digunakan untuk melakukan pembersihan data dengan mengisi nilai yang kosong agar dataset lengkap. Data numerik diisi dengan Median, sedangkan data teks diisi dengan Most Frequent Value.

6.3 Number to String#

Mengubah tipe data kolom PassengerId dan Survived dari angka menjadi teks agar komputer mengenalinya sebagai kategori, bukan nilai matematika.

6.4 Python Script#

Node Python Script digunakan untuk membuat model Gaussian Naive Bayes menggunakan library scikit-learn. Pada node ini, data dari KNIME diambil lalu diproses menggunakan bahasa pemrograman Python untuk melakukan klasifikasi pada dataset Titanic.

Kode yang digunakan pada node Python Script adalah sebagai berikut:

import knime.scripting.io as knio
import pandas as pd
from sklearn.naive_bayes import GaussianNB

df = knio.input_tables[0].to_pandas()
df_clean = df.dropna(subset=['Survived', 'Age', 'Fare', 'Pclass'])

X = df_clean[['Pclass', 'Age', 'SibSp', 'Parch', 'Fare']]
y = df_clean['Survived'].astype(int)

model = GaussianNB()
model.fit(X, y)

df_clean['prediction'] = model.predict(X)

knio.output_tables[0] = knio.Table.from_pandas(df_clean)

6.5 Secorer#

Node Scorer berfungsi untuk mengukur tingkat keberhasilan model dalam melakukan prediksi. Caranya adalah dengan membandingkan hasil tebakan model dengan data asli yang ada di dataset.

  • First Column (Survived): Mengambil data asli/aktual dari dataset Titanic.

  • Second Column (prediction): Mengambil data hasil prediksi dari node Python Script.

  • Tujuan: Menghitung nilai akurasi untuk mengetahui seberapa presisi model dalam memprediksi keselamatan penumpang.

8. Perhitungan Evaluasi#

\[Accuracy = \frac{TP + TN}{n} \times 100\%$$$$Accuracy = \frac{38 + 239}{418} \times 100\%$$$$Accuracy = \frac{277}{418} \times 100\% = 66,26\%\]

Model Gaussian Naive Bayes yang diimplementasikan pada dataset Titanic menghasilkan tingkat akurasi sebesar 66,26%. Nilai ini menunjukkan bahwa model cukup mampu mengklasifikasikan penumpang, meskipun masih terdapat selisih prediksi yang cukup signifikan.

9. Analisis#

Berdasarkan hasil pengujian, model memiliki kemampuan prediksi yang lebih akurat pada label negatif (penumpang tidak selamat) dibandingkan label positif. Hal ini terlihat dari tingginya angka True Negative (239) dibandingkan True Positive (38) pada Confusion Matrix. Ketimpangan ini terjadi karena distribusi data asli Titanic memang didominasi oleh penumpang yang tidak selamat. Meskipun penggunaan fitur Pclass, Age, SibSp, Parch, dan Fare sudah cukup baik, adanya 114 False Negative menunjukkan bahwa model Gaussian Naive Bayes masih kesulitan mengenali pola spesifik dari penumpang yang selamat.

10. Kesimpulan#

Dari hasil analisis yang dilakukan ini berhasil mengimplementasikan alur kerja data science di KNIME, mulai dari preprocessing (penanganan missing value menggunakan median dan modus) hingga tahap pemodelan. Penggunaan algoritma Gaussian Naive Bayes melalui Python Script menghasilkan akurasi sebesar 66,26%. Secara keseluruhan, model ini sudah cukup layak (fair) untuk melakukan klasifikasi awal, namun diperlukan pengembangan lebih lanjut seperti penambahan fitur atau penggunaan algoritma lain untuk meningkatkan akurasi prediksi keselamatan penumpang di masa mendatang.
