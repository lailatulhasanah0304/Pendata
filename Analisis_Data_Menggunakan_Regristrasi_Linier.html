2. Langkah Pengerjaan di GeoGebra#

  • Memasukkan Titik Koordinat

Masukkan titik satu per satu pada bagian input.

A = (2,2)
B = (4,3)
C = (3,5)
D = (3,4)
E = (3,3)
F = (4,5)
G = (5,6)

Setelah dimasukkan, titik akan muncul pada bidang koordinat.

  • Membuat Scatter Plot

Scatter plot terbentuk otomatis setelah seluruh titik dimasukkan ke bidang koordinat.

Scatter plot digunakan untuk melihat pola hubungan antara variabel X dan variabel Y.

  • Membuat Garis Regresi Linier

Pada bagian input GeoGebra ketik:

L = FitLine({A,B,C,D,E,F,G})

Kemudian tekan Enter.

GeoGebra akan membuat garis regresi linier otomatis berdasarkan titik-titik yang telah dimasukkan

  • Menampilkan Persamaan Garis

Setelah garis regresi muncul:

- Persamaan garis akan tampil di bagian kiri GeoGebra.
- Garis menunjukkan hubungan linear antara variabel X dan Y.

Menghitung Koefisien Regresi#

Rumus koefisien regresi:

\[ b = \frac{n\sum xy - (\sum x)(\sum y)} {n\sum x^2 - (\sum x)^2} \]

Rumus intercept:

\[ a = \frac{\sum y - b(\sum x)}{n} \]

Substitusi Nilai#

Diketahui:

  • (n = 7)

  • (\sum x = 26)

  • (\sum y = 28)

  • (\sum x^2 = 104)

  • (\sum xy = 112)

Menghitung Nilai b#

\[ b = \frac{ 7(112) - (26)(28) }{ 7(104) - (26)^2 } \]
\[ b = \frac{ 784 - 728 }{ 728 - 676 } \]
\[ b = \frac{56}{52} \]
\[ b = 1.0769 \]

Menghitung Nilai a#

\[ a = \frac{ 28 - (1.0769)(26) }{ 7 } \]
\[ a = \frac{ 28 - 28 }{ 7 } \]
\[ a \approx 0 \]

Persamaan Regresi#

\[ y = 0 + 1.0769x \]

atau dapat ditulis:

\[ y = 1.0769x \]

4. Persamaan Regresi#

Persamaan regresi yang diperoleh adalah:

y = 1.077x

5. Implementasi Menggunakan Python dan Sklearn#

Kode program menggunakan library sklearn:

import numpy as np
from sklearn.linear_model import LinearRegression

# Dataset
X = np.array([2,4,3,3,3,4,5]).reshape(-1,1)
Y = np.array([2,3,5,4,3,5,6])

# Membuat model regresi
model = LinearRegression()

# Training model
model.fit(X,Y)

# Menampilkan hasil regresi
print("Koefisien Regresi :", model.coef_[0])
print("Intercept :", model.intercept_)

# Persamaan regresi
print("Persamaan Regresi :")
print(f"y = {model.coef_[0]:.2f}x + {model.intercept_:.2f}")

Koefisien Regresi : 1.05
Intercept : 0.3999999999999999
Persamaan Regresi :
y = 1.05x + 0.40
